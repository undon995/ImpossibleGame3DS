# The Impossible Game 3DS — Beta 0.7

**Pre-release source preview** · `v0.7.0-beta.1`

Unofficial Nintendo 3DS homebrew project. The source is available for building with your own legally obtained copy of the game's assets.

## Included
- C/libctru game engine for Old 3DS
- Five-stage level-data importer
- One-button jump input and scrolling levels
- Practice Mode checkpoints (experimental)
- Attempt counter reset when leaving a level
- Original-style cube rotation, fade and background event support

## Known beta problems
- **The last level is not fully working.** A future update is planned.
- Some jumping/collisions and level-completion conditions are not yet faithful.
- Music synchronization, long-session performance and Practice Mode remain under test.

## How to play
The source must be built locally with devkitPro and your own copy of the commercial game assets. This source preview does not contain installable binaries or third-party graphics/music.

Please report bugs at https://github.com/undon995/ImpossibleGame3DS/issues
